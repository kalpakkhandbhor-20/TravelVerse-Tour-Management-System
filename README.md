TravelVerse – Tour Management System | MySQL
📌 Project Overview

TravelVerse is a Tour Management System developed using MySQL to manage travel-related data, including customers, bookings, tours, and reviews. This project demonstrates SQL skills through database design, data management, and analytical queries.

🎯 Project Objectives
Design a structured relational database for a tour management system.
Manage customer, tour, booking, and review information.
Retrieve meaningful insights using SQL queries.
Practice joins, aggregate functions, subqueries, and other SQL concepts.

🛠️ Tools & Technologies
Database: MySQL
Language: SQL
Concepts: Database Design, Joins, GROUP BY, Aggregate Functions, Subqueries, Views, CTEs, Window Functions

🗄️ Database Structure
The project consists of 7 relational tables designed to organize tour management data efficiently.
The database supports customer information, tour-related details, bookings, reviews, and other related records.

📊 Project Highlights
Designed a relational database with 7 tables.
Created and executed 17 SQL queries.
Worked with customer records and review data.
Used joins to retrieve data from multiple tables.
Applied aggregate functions and GROUP BY for data analysis.
Practiced subqueries, views, CTEs, and window functions.
Extracted meaningful insights from structured data.

💡 Key SQL Concepts Demonstrated
Joins: Combined related data from multiple tables.
Aggregate Functions: Used COUNT(), SUM(), AVG(), MIN(), and MAX().
GROUP BY: Summarized data across different categories.
Subqueries: Retrieved data based on nested query results.
Views: Created reusable virtual tables.
CTEs: Simplified complex queries using Common Table Expressions.
Window Functions: Performed analytical calculations across related rows.

📈 Learning Outcomes
Improved understanding of relational database design.
Gained practical experience writing SQL queries.
Learned to retrieve and analyze data from multiple tables.
Strengthened problem-solving and database management skills.
